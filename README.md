## ✨ Features

- **3D Interactive Hero:** Three.js gold metallic TorusKnot with wireframe shell, dynamic point light orbiting, and 360° drag rotation with smooth damping.
- **Scroll-Driven Motion:** GSAP + ScrollTrigger scroll reveals, section stagger animations, and background parallax layers.
- **Micro-Interactions:** Custom button scale effects, elevated card hover transitions with subtle gold ambient glows, and responsive nav underline animations.
- **Responsive Across All Breakpoints:** Tested and optimized for mobile (375px), tablet (768px), laptop (1280px), and ultra-wide desktop (1920px).
- **SEO & Social Metadata:** Open Graph cards, Twitter metadata, and structured search tags.
- **Accessibility:** WCAG 2.5.5 touch target sizes (≥44px), semantic HTML5 landmarks, and full `prefers-reduced-motion` compliance.

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Build Tool:** Vite 5
- **Styling:** Tailwind CSS v4 (`@theme` design tokens)
- **3D Graphics:** Three.js
- **Animations:** GSAP + ScrollTrigger

## 📦 Getting Started

```bash
# Clone repository
git clone https://github.com/phanikaushik2630-ship-it/Portfolio-.git

# Navigate into project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Create production build
npm run build
```
